QUY TẮC TUYỆT ĐỐI:
1. Làm ĐÚNG theo kế hoạch — mỗi task có code cụ thể, file path cụ thể, lệnh test
   cụ thể. KHÔNG tự sáng tạo khác đi. KHÔNG bỏ task.
2. TDD: với task có test, VIẾT TEST TRƯỚC → chạy thấy FAIL → viết code → chạy thấy
   PASS. Đúng thứ tự.
3. KHÔNG chạy `git commit`. Chỉ viết code + chạy test. (Người review sẽ commit sau.)
4. BUILD/TEST cần biến môi trường vì path dự án có khoảng trắng ("level 3") làm
   clang CGO vỡ. TRƯỚC MỌI lệnh go, chạy:
   export CGO_LDFLAGS="-L$TMPDIR/sfs-libs"; ln -sfn "/Users/tatlatat/Documents/level 3/libs" "$TMPDIR/sfs-libs"
   (kế hoạch đã ghi lệnh này trong từng step — bám theo).
5. KHÔNG đụng file ngoài phạm vi kế hoạch. Các file kế hoạch cho sửa:
   - TẠO: internal/intent/event.go, internal/intent/log.go, internal/intent/log_test.go,
     internal/webui/event_test.go
   - SỬA: internal/store/store.go, internal/engine/engine.go, internal/webui/webui.go,
     internal/webui/assets/index.html, (.gitignore nếu cần — nhưng .sfsindex/ đã có).
6. RÀNG BUỘC THIẾT KẾ (từ kế hoạch): 100% LOCAL (events.jsonl trong .sfsindex/, không
   gửi mạng), Chunk.ModTime là int64 Unix giây (không time.Time, để gob gọn + tương
   thích ngược), log append-only + rotate ở 5000 event.
