NHIỆM VỤ GĐ3 (Time Profile — nhịp thời gian):
- Thêm TimeProfile vào Profile: học "giờ-đỉnh" hay mở mỗi file/chủ đề từ events
  (giờ-trong-ngày của các event open). Công thức S_time = Gaussian quanh giờ-đỉnh
  (σ=2h, khoảng cách giờ VÒNG TRÒN) như SCORING_DESIGN mục 1.4.
- Thêm yếu tố timeMatch vào Predict (trọng số wTime). Cập nhật công thức:
  score = wCos·cos + wRec·rec + wFreq·freq + wTime·timeMatch.

NHIỆM VỤ GĐ4 (Feedback Loop — TỰ HỌC trọng số, PHẦN KHÓ NHẤT):
- intent.Learn(events) cập nhật w1..wN bằng Passive-Aggressive / online update như
  SCORING_DESIGN mục 5.2: với cặp (f+ click, f- bỏ qua), nếu Score(f+) < Score(f-)+margin
  thì w_i += η·E·(S_i(f+) - S_i(f-)), rồi clamp w_i>=0.05 + chuẩn hoá Σw=1. η=0.02, margin=0.05.
- CHỐNG POSITION BIAS (mục 5.1): negative = file ĐÃ HIỆN TRÊN mà bị bỏ qua (top trên
  click), KHÔNG phải mọi file. Dùng Rank + Shown trong events.
- Lưu trọng số đã học vào .sfsindex (profile.gob hoặc weights.json), Predict đọc dùng.
- Offline Replay (mục 6): viết 1 tool/test Go quét events.jsonl theo thời gian, mỗi
  app_open chạy Predict, so file user mở SAU đó với top-5 → tính HitRate@5 + MRR@5.
